00 / ABOUT

About.

ANTISPICE is a lightweight, portable, and customizable circuit simulator.

It offers a clean Python API as well as a web service for interactive use, making it ideal for those who want to learn and experiment.

It relies heavily on code-generation techniques and simulates with the stiffly accurate Radau-IIA method. ANTISPICE prioritizes elegance and flexibility rather than interoperability with legacy tools.

An educational and research tool—not a traditional EDA suite. Contributions and feedback are welcome.

01 / HOW IT WORKS

A circuit laboratory in the browser.

  • Models / parts / circuitsModel-drivenCompose circuits from readable model and part libraries. Parameters resolve from part defaults to instance overrides, while equations and named internal quantities remain inspectable.
  • Symbolic → WebAssemblyCompiled solversThe Python core turns each circuit's equations into a compact numerical solver. The actual simulation runs responsively inside the browser as a WebAssembly module. The Python core offers NumPy and SciPy targets as well, enabling programmatic circuit analysis.
  • Nonlinear / transient / ACSimulation InsightsSolve operating points, transient response, and linearized small-signal AC response. Select net, port, and model-defined signals directly from the schematic.

02 / QUICK MANUAL

The useful gestures.

Navigate
Drag empty canvas to pan. Pinch or use the wheel to zoom. Plots use the same gestures; Fit resets their view.
Place + wire
Choose a component, then tap once to place it. Tap a port to begin a wire, tap the grid for bends, and tap a port or wire to finish.
Select + edit
Tap an object to select it; drag to move it. Selected ports stay visible. Use the contextual actions or keyboard to duplicate and delete.
Analyze
Choose Simulate or AC, select signals on the schematic or in the lists, configure the analysis, then run it.
