00 / ABOUT

About.

ANTISPICE is a lightweight, portable, and customizable circuit simulator.

It offers a clean Python API as well as a web service for interactive use, making it ideal for those who want to learn and experiment.

It relies heavily on code-generation techniques and simulates with the stiffly accurate Radau-IIA method. ANTISPICE prioritizes elegance and flexibility rather than interoperability with legacy tools.

An educational and research tool—not a traditional EDA suite. Contributions and feedback are welcome.

01 / HOW IT WORKS

A circuit laboratory in the browser.

  • Models / parts / circuitsModel-drivenCompose circuits from readable model and part libraries. Parameters resolve from part defaults to instance overrides, while equations and named internal quantities remain inspectable.
  • Symbolic → WebAssemblyCompiled solversThe Python core turns each circuit's equations into a compact numerical solver. WebAssembly then runs the actual analysis responsively inside the browser.
  • Nonlinear / transient / ACUseful analysisSolve operating points, adaptive implicit transients, and linearized small-signal frequency responses. Select net, port, and model-defined signals directly from the schematic.

No specialist workflow required. Open the editor, draw something, and inspect what happens. The details remain available when you want them.
